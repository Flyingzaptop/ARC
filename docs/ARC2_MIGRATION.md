# ARC 2 migration

ARC 2 adds an application-facing semantic frontend before native D3D12 forwarding. The previous observer path remains available as a baseline and fallback. `arc2::Runtime` owns API-time object identity, descriptor versions, command state, work, submissions, synchronization, and Present links. `feed_resource_graph` projects selected known IR facts into the existing `ResourceGraph`. The current ARC 2 observer runs the existing resource semantic classifier and scene summary against that projection; it does not yet connect the IR to the legacy temporal visibility, visual importance, perceptual controller, memory planner, or broader optimizer action pipeline.

The graph bridge is deliberately lossy: it forwards known resource uses from submissions whose currently checked state is consistent, while symbolic shader ranges and unknown accesses remain only in IR. `Submission.complete` does not mean all resource dependencies are known. Current validation checks a descriptor table's base generation but not every non-base slot in its declared interval. The graph also lacks read evidence for `ReadWrite`, copy-specific events, descriptor-view history, resource destruction, and heap sizes. Its current consumers are read-only. Memory planning, residency changes, aliasing, and wider rewrites require explicit dependency closure checks before this projection can be an actuation input. Legacy observer events alone cannot certify the direct-IR state of a call. The old hooks and experiments are retained for comparisons.

Recorded clear work describes the application's requested API sequence. The optimize callback can elide a redundant clear after recording it, so a `Clear` work item or bridged write is not proof of a native GPU clear. The aggregate accepted-action counter does not identify which work item executed or its native cost. Marker/event calls are forwarded but do not currently divide IR work for attribution. `SOSetTargets` is also forwarded without captured stream-output bindings, leaving those draw writes outside the graph. These are measurement and dependency limits, not claims of a demonstrated visual failure in the current RTV-clear rewrite. No ARC 2 rewrite uses stream-output evidence today.

Migration proceeds per API surface: wrap a successful native call, update `Runtime` at the application boundary, and forward to native D3D12 while preserving HRESULT and COM identity. Calls without modeled semantics must be reported as unsupported. The only current ARC 2 rewrite is a narrow consecutive identical RTV clear case, with a same-generation target descriptor and byte-exact color/rectangle signature; it is enabled only in optimize mode. Its observed quality and performance must be established by the independent test harness. The temporal visibility, visual importance, perceptual controller, admission/rollback policy, and memory actions remain legacy or unmigrated components rather than ARC 2 capabilities.

The current source captures typed API arguments for Draw, DrawIndexed, Dispatch and ExecuteIndirect, plus vertex stride, index format and bounded full scissor arrays. This improves API-time intent records without executing or interpreting indirect argument buffers, expanding bundles, or closing shader/resource dependencies. The focused portable IR test passed for these fields. The owned native binding test verified schema-1 dispatch payloads and GPU output, while draw, indirect and IA/scissor fields still lack equivalent native assertions. Results from earlier five-codebase matrices cannot be relabeled as validation of the revised fields. The only current mutation remains the exact repeated RTV clear rule. Other legacy reversible actions require their own semantic adapters, safety proofs and independent quality admission before migration.

Before widening the bridge, test a non-base descriptor overwrite within a reflected table range, a symbolic shader read beside a known render-target write, `ReadWrite` accounting, copy accounting, and retained work eviction. These cases distinguish a useful partial graph from a closed dependency graph; no percentage reduction in unknowns should be claimed without measurements against the legacy observer on the same workload.
