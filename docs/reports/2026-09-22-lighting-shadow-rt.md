# Освещение, отражения, фильтрация теней и inline RT — промежуточный результат

Добавлены рабочие преобразования для поддержанных структур шейдера:

- Пиксельные шейдеры: независимые нормированные выборки 100/75/50/25%,
  применимые к соответствующим фильтрам освещения/отражений.
- Пиксельные шейдеры: распознанный PCF5x5 заменяется девятью выборками с весом1/9.
- Compute: внешний набор независимых inline RayQuery лучей сокращается,
  полное Proceed каждого оставленного луча сохраняется. Проверен реальный TLAS.
  Поддержан строгий трёхблочный шаблон с CommittedStatus; зависимые лучи отклоняются.
- Общий процент независимых выборок используется для texture/ray means.
  Это не универсальное управление всеми алгоритмами освещения или RT.

Нормировка относится к сохранённому подмножеству. Репрезентативность первых
выборок и субъективное качество этим не гарантируются. Критик не включается.

## Проверки

Короткие native GPU-тесты: независимые HLSL-эталоны, нейтральное исполнение,
откат, живой перехватчик для всех трёх механизмов — PASS.
Первые расширенные тесты выявили ошибки порядка действий самого стенда:
новые PSO создавались после passive mode; ожидание подготовки использовало
устаревший суммарный счётчик. После исправления повторные и финальные проверки прошли.

Cauldron: один15-секундный прогон ARC и один15-секундный baseline без DLL.
GPU span стенда:12.3857 ->9.8557мс, около20.4% меньше. Для одинаковых scene_frame
600..1199:12.4343 ->9.6187мс, около22.6% меньше. Это одна предварительная пара,
не доказательство повторяемости и не отдельный эффект новых регуляторов.
Частоты: baseline1897–1942МГц; ARC1912–2017МГц. Лимит мощности менялся.

Совпадающий цикл камеры, средние GPU-миллисекунды:

В Cauldron подготовлен один поддержанный пиксельный PCF-вариант; пиксельные
sample-mean и inline-RT варианты на этой сцене не обнаружены. Их работа доказана
native GPU-стендами, а не этим сравнением. GPU span — интервал таймеров стенда,
не полная атрибуция всех собственных GPU-команд ARC. Ошибок pixel-модуля нет;
остановка подтверждена. Измерение изображения/субъективного качества не выполнялось.
